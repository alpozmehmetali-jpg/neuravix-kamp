# Görev Noktası Okuyucu (2. Hafta Projesi)

Bu proje, `gorevler.geojson` dosyasındaki GPS görev noktalarını okuyarak nesne tabanlı (OOP) bir yapıda tutar ve Haversine formülü kullanarak ardışık noktalar arasındaki mesafeler ile toplam rota uzunluğunu metre cinsinden hesaplar.

## Gereksinimler
- Python 3.12 (Harici kütüphane gerektirmez; standart `json` ve `math` modülleri kullanılır.)

## Çalıştırma
Terminalde `hafta2/` klasörünün içine girerek aşağıdaki komutu çalıştırın:

```bash
python3 main.py
